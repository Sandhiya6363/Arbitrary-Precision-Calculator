# Arbitrary Precision Calculator (APC)

## 📌 Project Description
The Arbitrary Precision Calculator (APC) is a C programming project designed to perform arithmetic operations on very large integers that exceed the limits of standard C data types. It processes numbers digit by digit using suitable data structures to avoid integer overflow and maintain accuracy.

## 🎯 Objectives
- Perform arithmetic operations on large integers.
- Overcome the limitations of standard C data types.
- Apply data structures, pointers, and modular programming concepts.
- Implement arithmetic algorithms for accurate results.

## ⚙️ Features
- Addition of large numbers
- Subtraction of large numbers
- Multiplication of large numbers

## 🚀 How to Compile and Run

### 1. Clone the repository
```bash
git clone https://github.com/Sandhiya6363/Arbitrary-Precision-Calculator.git
cd Arbitrary-Precision-Calculator
```

### 2. Compile the project
```bash
make
```

### 3. Run the calculator
Use the executable generated by your Makefile. For example, if the executable is named `apc`:

